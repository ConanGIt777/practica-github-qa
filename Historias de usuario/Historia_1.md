# HU-01: Login y Seguridad

## Historia de Usuario

Como usuario registrado del sistema,
quiero iniciar sesión mediante mis credenciales,
para acceder a las funcionalidades permitidas según mi rol.

## Criterios de Aceptación

- Las contraseñas deben almacenarse encriptadas en la base de datos.
- El sistema debe bloquear el acceso después de 3 intentos fallidos consecutivos.
- El usuario debe ser redirigido a la interfaz correspondiente según su rol (Administrador o Usuario).
