# HU-02: CRUD de Plantas e Inventario

## Historia de Usuario

Como administrador del huerto,
quiero registrar, actualizar, consultar y eliminar plantas,
para mantener actualizado el inventario agrícola.

## Criterios de Aceptación

- El sistema debe validar los campos obligatorios Nombre y Especie.
- No debe permitirse registrar plantas con IDs duplicados.
- El sistema debe mostrar el mensaje "Guardado con éxito" después de registrar o actualizar una planta.
