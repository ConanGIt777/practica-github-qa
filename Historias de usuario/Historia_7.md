# HU-07: Reportes PDF Mensuales

## Historia de Usuario

Como administrador del sistema,
quiero generar reportes mensuales en formato PDF,
para disponer de información consolidada sobre las actividades del huerto.

## Criterios de Aceptación

- El PDF debe incluir el logotipo del proyecto en el encabezado.
- Debe contener una tabla resumen de cosechas realizadas durante el mes.
- Debe contener una tabla resumen de actividades de riego del mes.
- La descarga del archivo debe iniciar en menos de 5 segundos.
