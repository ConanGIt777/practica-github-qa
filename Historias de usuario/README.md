# Huertos Comunitarios Inteligentes

## Descripción

Aplicación web para la gestión de huertos comunitarios que permite administrar parcelas, plantas, calendarios de riego y cosecha, visualizar ubicaciones geográficas, recibir consejos agrícolas, generar reportes estadísticos y controlar el acceso de usuarios mediante autenticación segura.

## Funcionalidades Principales

### Inicio de sesión y seguridad
Acceso seguro mediante usuario y contraseña con validación de credenciales, control de roles y protección de datos.

### Gestión de plantas e inventario
Registrar, consultar, actualizar y eliminar plantas dentro del inventario del huerto.

### Calendario de riego y cosecha
Visualizar eventos agrícolas organizados por fechas para planificar actividades del huerto.

### Geolocalización y mapas
Consultar la ubicación de parcelas comunitarias mediante mapas interactivos.

### Microservicio de consejos agrícolas
Obtener recomendaciones personalizadas según la etapa de desarrollo de los cultivos.

### Dashboard estadístico
Visualizar indicadores, gráficos y estadísticas relacionadas con la producción agrícola.

### Reportes PDF mensuales
Generar y descargar informes en formato PDF con información resumida de actividades y cosechas.
