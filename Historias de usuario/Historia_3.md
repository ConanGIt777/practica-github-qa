# HU-03: Calendario de Riego

## Historia de Usuario

Como usuario del sistema,
quiero visualizar un calendario de actividades agrícolas,
para conocer las fechas de riego y cosecha programadas.

## Criterios de Aceptación

- Los eventos de riego deben mostrarse en color azul.
- Los eventos de cosecha deben mostrarse en color verde.
- El usuario debe poder navegar entre los diferentes meses del calendario.
- Las fechas pasadas deben mostrarse deshabilitadas o en color gris.
