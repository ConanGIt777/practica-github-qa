# HU-05: Microservicio de Consejos

## Historia de Usuario

Como usuario del huerto,
quiero recibir consejos agrícolas personalizados,
para mejorar el cuidado de mis cultivos según su etapa de desarrollo.

## Criterios de Aceptación

- El sistema debe mostrar un consejo diferente para la etapa de Siembra.
- El sistema debe mostrar un consejo diferente para la etapa de Crecimiento.
- El sistema debe mostrar un consejo diferente para la etapa de Cosecha.
- El tiempo de respuesta del servicio debe ser menor a 1 segundo.
