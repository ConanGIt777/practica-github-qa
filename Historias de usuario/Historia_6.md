# HU-06: Dashboard Estadístico

## Historia de Usuario

Como administrador del sistema,
quiero visualizar estadísticas del huerto mediante gráficos,
para analizar el rendimiento de la producción agrícola.

## Criterios de Aceptación

- Debe mostrarse un gráfico de barras para "Cosechas por Mes".
- Debe mostrarse un gráfico de pastel para "Estado de Salud de Plantas".
- Los datos deben actualizarse automáticamente al cargar la página.
